# HUEVOKE Studio Website

A responsive, editorial ecommerce preview for HUEVOKE, a Hyderabad-based sculptural wall-art studio.

## Preview the website

The simplest option is to download the project and double-click `index.html`.

For a local web preview:

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Included

- Responsive desktop and mobile layouts
- Form, Elements and Indian Minimal collections
- Product catalogue and detail views
- INR placeholder pricing and India-wide shipping messaging
- Custom artwork builder
- Upload-and-visualize room prototype
- Artwork cutouts extracted from the HUEVOKE catalogues

## Share online

This static website can be hosted directly with GitHub Pages, Netlify, Vercel or Cloudflare Pages. No build command is required; the publishing directory is the repository root.

## Important

Prices, lead times and commerce actions are prototype content. Confirm production specifications and connect a checkout backend before accepting live orders.
